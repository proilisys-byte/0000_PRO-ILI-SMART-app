### 🚀 통합 프롬프트(v0.4) 장점 취합 및 융합 계획

두 프롬프트의 강력한 요소들만 결합하여, **"기술적으로 완벽하면서도, B2B 고객의 신뢰를 주는 워크플로우 중심의 고해상도 프롬프트"**를 수립하는 계획입니다.

#### 1. 역할 및 기술 스택 (v0.2 채택)
*   아웃풋 형태를 v0.3의 단순 HTML이 아닌, **v0.2의 `Next.js + Tailwind CSS + shadcn/ui + Framer Motion` 스택으로 지정**합니다.
*   가짜 이미지(Placeholder)를 지양하고 Tailwind로 CSS UI 목업을 만들라는 v0.2의 디테일한 지시를 유지합니다.

#### 2. 카피라이팅 및 톤앤매너 (v0.3 중심 + v0.2 수치 융합)
*   출력 언어는 **한국어**로 지정하되, **v0.3의 B2B SaaS 카피라이팅 가이드(추상적인 수식어 지양, 실무적이고 단호한 어조)**를 엄격하게 적용합니다.
*   "혁신적인 인공지능" 같은 말 대신 "품질 운영을 하나의 연결된 워크플로우로 전환"과 같은 실무적 카피를 사용합니다.
*   여기에 **v0.2의 강력한 정량적 ROI 수치(120시간 → 10분 단축 등)**를 근거 지표로 삽입하여 설득력을 극대화합니다.

#### 3. 시각적 테마 및 디자인 시스템 (융합)
*   **v0.2의 컬러 팔레트**(Deep Space Black 배경 + Vibrant Cyan/Emerald Green 포인트)와 **글래스모피즘**을 가져옵니다.
*   동시에 **v0.3의 "정제되고 차분한(Premium but restrained) 디자인" 원칙**을 더해, 형광색과 글로우 효과가 너무 가볍게 남용되지 않도록 제어합니다(네온 그라데이션, 전형적인 SaaS 카드 템플릿 사용 금지 등).

#### 4. 랜딩페이지 섹션 구조 (v0.3의 10단계 뼈대 적용)
v0.3의 탄탄한 10단계 서사 구조를 뼈대로 삼고 내용물을 v0.2의 구체적인 요소로 채웁니다.
1.  **Hero:** v0.3의 명확한 가치 제안 + v0.2의 추상적 UI 목업(파형 → 문서 변환)
2.  **Problem (Pain Points):** 품질 팀의 3~5가지 현실적 문제점 (v0.3)
3.  **Solution & Workflow:** 단순 기능 카드가 아닌, 현장 수집 → 자동 문서화 → NC 대응 → 관리자 분석으로 이어지는 하나의 파이프라인으로 소개 (v0.3 강조점)
4.  **Core Features:** Zero-UI, Smart Audit 등 4대 핵심 기능 소개 (v0.2)
5.  **Metrics & Expected Outcomes:** 120h → 10m, ROI 시각화 (v0.2 & v0.3)
6.  **Trust & Compliance:** ISO 9001, RBAC, Insert-only 등 보안/무결성 강조 (v0.2 & v0.3)
7.  **Final CTA:** 전환율을 높이는 B2B 폼 및 데모 신청 (v0.3)
