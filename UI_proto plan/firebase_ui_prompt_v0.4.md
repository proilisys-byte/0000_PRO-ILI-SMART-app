# Firebase Studio 용 PRO ALI SMART 통합 랜딩페이지 프롬프트 (v0.4)

아래의 프롬프트를 복사하여 Firebase Studio(또는 v0, Project IDX, Cursor 등 AI UI 생성 도구)에 입력하십시오. v0.2의 시각적 디테일과 v0.3의 B2B 워크플로우 논리가 완벽하게 결합된 최종 통합 프롬프트입니다.

---

## 📋 프롬프트 복사 영역

**[역할 및 목적 (Role & Objective)]**
당신은 최고 수준의 B2B SaaS UI/UX 디자이너이자 숙련된 Frontend 엔지니어(Next.js, React, Tailwind CSS, shadcn/ui 전문)입니다.
제공된 컨텍스트를 기반으로 'PRO ALI SMART(스마트 제조 품질혁신 플랫폼)'의 **사업화 랜딩페이지(Landing Page)** 코드를 완벽하게 구현해주세요.

### 🌟 1. Global UI/UX 원칙 통합 (The Core Rules)
1. **신뢰성(Trustworthy) & B2B Tone of Voice:**
   - 과장된 마케팅 용어("혁신적인", "미래를 여는" 등)를 엄격히 배제하고 실무적이고 단호한 어조를 사용합니다.
   - 예: "품질 운영을 하나의 연결된 워크플로우로 전환", "120시간의 문서 작업을 10분으로 단축"
   - 제품은 단순한 AI 챗봇이 아닌 '제조 현장을 위한 품질 운영 시스템'으로 명확히 포지셔닝합니다.
2. **반응형 & Mobile-first (max-w-md 고려):**
   - 모바일(sm), 태블릿(md), 데스크탑(lg/xl) 화면에서 레이아웃이 완벽하게 대응되어야 합니다. 모바일 퍼스트 접근을 취하며 좁은 화면(max-w-md)에서도 핵심 콘텐츠가 뭉개지거나 밀려나지 않게 설계합니다.
3. **디자인 시스템 & Color Palette (Premium but Restrained):**
   - **테마:** Dark Mode 중심의 정제되고 차분한 엔터프라이즈 SaaS 테마.
   - **컬러 팔레트:** Deep Space Black (#0F172A) 배경. 포인트 컬러로 Vibrant Cyan (AI/효율 상징) 및 Emerald Green (통과/무결성 상징)을 절제하여 사용. 형광색이나 네온 그라데이션의 과도한 남용을 금지합니다.
   - **UI 패턴:** Glassmorphism (반투명 유리 텍스처 효과), 부드러운 블러(Blur) 백그라운드를 과하지 않게 적용. 뻔하고 전형적인 3-column 기능 카드 템플릿 사용을 피하십시오.
   - **인터랙션:** 스크롤 시 부드러운 Fade-in/Slide-up (Framer Motion 등), 카드 호버 시 미세한 크기 확대 등 마이크로 애니메이션을 적극 활용하여 고급스러움을 더합니다.

### 🌟 2. 랜딩페이지 섹션별 깐깐한 레이아웃 (Step-by-Step Layouts)

**Step 1: Hero Section (최상단 메인 영역)**
- **콘텐츠:** "품질 운영을 하나의 연결된 워크플로우로 전환." (Headline) / "현장 데이터 수집부터 원청 Audit 증빙, 긴급 NC 시정까지. 제조 품질팀을 위한 단일 플랫폼." (Sub-headline)
- **레이아웃 지시사항:** 
  - 좌우 분할(Split) 레이아웃. 좌측엔 텍스트와 2개의 CTA 버튼(Primary: `[무료 도입 컨설팅 신청]`, Secondary: `[워크플로우 보기]`). Primary 버튼엔 절제된 글로우 효과 적용.
  - 우측엔 현장의 음성 파형(STT) 코드가 클라우드를 거쳐 대시보드 리포트로 변환되는 과정을 보여주는 세련된 **추상적 UI Mockup**을 배치 (Tailwind CSS와 아이콘 활용, 절대 이미지 태그 금지).

**Step 2: Problem (Pain Points - 품질팀의 한계)**
- **콘텐츠:** 품질 팀의 현실적 문제점 (종이 기록의 한계, Audit 준비를 위한 수작업 매핑 120h, 데이터 분실 및 NC 추적 불가 등).
- **레이아웃 지시사항:** 
  - 가로로 스크롤되거나 약간 어긋난 그리드로 정렬된 3~4개의 경고/주의 느낌의 미니멀한 카드 배치.
  - 각 카드 상단에 적절한 Lucide React 아이콘(AlertTriangle, FileWarning 등)을 배치하고, 은은한 주황/적색 틴트 배경을 활용해 Pain Point임을 시각적으로 강조.

**Step 3: Solution & Workflow (워크플로우 중심의 해결책)**
- **콘텐츠:** 단순 기능 나열이 아닌, "현장 수집 → 자동 문서화 → NC 대응 → 관리자 분석"으로 이어지는 하나의 파이프라인.
- **레이아웃 지시사항:**
  - 중앙을 관통하는 수직 타임라인(Timeline) 형태 또는 좌우로 흐르는 프로세스 다이어그램(Process Flow) 형태의 UI를 Tailwind로 직접 구현.
  - 각 단계별 연결선(Line)과 노드(Node)가 스크롤에 따라 점진적으로 밝아지거나 활성화되는 상태 표시 UI를 통해 "연결성"을 강력하게 시각화.

**Step 4: Core Capabilities (4대 핵심 기능)**
- **콘텐츠:** 🎙️ Zero-UI 수집기, 📄 Smart Audit 엔진, 🚨 NC Management, 📈 Lean COPQ / ROI.
- **레이아웃 지시사항:**
  - 크기가 서로 다른 비대칭 그리드(Bento Grid) 레이아웃을 사용하여 전형적인 카드 나열을 탈피.
  - 각 셀 내부에 실제 제품 UI의 일부를 엿볼 수 있는 마이크로 컴포넌트(상태 뱃지, 미니 차트, 코드 스니펫 등)를 CSS로 정교하게 그려서 배치. 가짜 이미지(`<img>` placeholder) 절대 사용 금지.

**Step 5: Trust, Security & Compliance (무결성과 보안)**
- **콘텐츠:** B2B의 핵심인 보안. ISO 9001 대응, RBAC, Insert-only DB 감사 로그, 데이터 유실률 0%.
- **레이아웃 지시사항:**
  - 다크하고 단단한 느낌을 주는 전체 폭(Full-width) 컨테이너.
  - 중앙에 커다란 쉴드(Shield) 아이콘 혹은 서버 랙(Server Rack) 모티프를 두고, 주변으로 보안 스펙들이 방사형으로 뻗어나가거나 신뢰감 있는 뱃지 리스트 형태로 촘촘히 정렬.

**Step 6: Expected Outcomes & Metrics (정량적 도입 성과)**
- **콘텐츠:** 120h → 10m (보고서 준비 시간 99% 단축), $0 (초기 인프라 도입비용), 1 Sprint (시스템 적용 기간).
- **레이아웃 지시사항:**
  - 대형 타이포그래피(Big Numbers) 적용. 숫자가 눈에 확 띄도록 화면의 중앙 또는 3-column 그리드에 여백(Whitespace)을 충분히 주어 배치. 숫자 색상은 시선을 끄는 Vibrant Cyan을 사용.

**Step 7: Final CTA & Footer (하단 전환 영역)**
- **콘텐츠:** "당신의 품질 비용(COPQ)을 지금 바로 영업 이익으로 전환하세요." + 컨설팅/데모 신청 폼.
- **레이아웃 지시사항:**
  - 시선을 집중시키는 중앙 정렬 카드형 폼. 이메일/회사명 입력 필드는 미니멀하고 고급스럽게 디자인.
  - 폼 아래에 로고, 저작권, 개인정보처리방침, Terms 등 기본 Footer를 깔끔하게 정렬.

### 🌟 3. 기술적 제약 및 코딩 요구사항 (Technical Constraints)
- **단일 파일 컴포넌트:** 제공하는 코드는 즉시 랜더링 가능한 완벽한 수준이어야 합니다. 분리된 파일 구조를 주지 마십시오.
- **CSS 프레임워크:** 모든 스타일링은 Tailwind Utility Class로만 작성 (임의의 커스텀 CSS 파일 추가 지양).
- **아이콘:** Lucide React 아이콘 라이브러리를 적극 활용.
- **더미 데이터 및 시각물:** 실제 현업 데이터를 모방하여 작성하고, 모든 UI 시각물(그래프, 대시보드 화면 등)은 Tailwind로 직접 그려진 코드 기반 목업(Mockup)이어야 합니다.
