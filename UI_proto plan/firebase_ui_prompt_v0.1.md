# 기대되는 사이트의 모습 (페이지 및 기능 구성)

제공해주신 5개의 UI Task 명세서를 바탕으로 그려본 **PRO ILI SMART 플랫폼**의 기대되는 페이지 구성과 핵심 기능 구성은 다음과 같습니다. 단일 테넌트 기반 B2B SaaS에 최적화된 모던하고 체계적인 엔터프라이즈 애플리케이션의 모습을 갖출 것입니다.

## 1. 페이지 구성 (Page Architecture)
Next.js의 App Router 기능을 활용해 비로그인(Auth) 그룹과 로그인(Dashboard) 그룹이 명확히 분리된 구조를 가집니다.

* **`(auth)` 라우트 그룹**
  * **로그인 페이지 (`/login`)**: LNB(사이드바)나 GNB(상단 네비게이션) 없이 화면 중앙에 집중된 깔끔한 인증 폼 페이지입니다. 사용자 계정 잠금 정보나 세션 만료 모달 등이 이곳에서 처리됩니다.

* **`(dashboard)` 라우트 그룹 (App Shell Layout)**
  * **공통 레이아웃 (App Shell)**: 화면 상단에 픽스된 **GNB**(테넌트 정보, 프로필, 알림)와 좌측에 픽스된 **LNB**(권한에 따라 동적으로 노출되는 메뉴)로 구성됩니다. GNB에는 다른 테넌트로 즉시 전환할 수 있는 **Tenant Switcher**가 포함됩니다.
  * **Audit Session List (`/dashboard/audit`)**: 수많은 감사(Audit) 세션을 한눈에 보는 목록 페이지입니다. 커서 기반 페이지네이션과 뱃지(Badge) 형태의 상태 표시기, 필터바가 상단에 위치합니다.
  * **Audit Workspace (`/dashboard/audit/[id]`)**: 단일 세션에 대한 모든 작업(생성, 폼 입력, 임시저장, 제출, 리포트 확인)이 한 화면에서 끊김 없이(Single Flow) 일어나는 통합 작업 공간입니다. (좌측 목록, 우측 폼/상세/STT 패널 등의 스플릿 뷰 형태가 예상됩니다.)
  * **Bulk Import Dashboard (`/dashboard/bulk-import`)**: 관리자(Admin) 전용 화면입니다. 현재 진행 중인 대량 데이터 업로드 작업(Job) 목록과 진행률, 오류 상황을 한눈에 관제할 수 있는 모니터링 형태의 뷰를 제공합니다.

## 2. 주요 기능 구성 (Feature & UX Configuration)

**① 보안 및 접근 제어 (Security & Auth)**
* **강력한 폼 밸리데이션**: 클라이언트단에서 비밀번호 정책(12자 이상, 3종 이상 조합)을 실시간으로 검증합니다.
* **계정 보호 UX**: 5회 이상 로그인 실패 시 남은 잠금 시간을 실시간 카운트다운으로 보여주며, 30분 유휴 상태 감지 시 자동 로그아웃 경고 모달을 띄웁니다.
* **Middleware 라우트 보호**: 인가되지 않은 사용자(Viewer)가 관리자 전용(Bulk Import 등) URL로 접근 시 즉시 차단하고 `unauthorized` 화면으로 넘깁니다.

**② Smart Audit (스마트 감사 및 평가)**
* **상태 머신 기반 제어**: 세션 상태(`Draft` → `InProgress` → `Submitted` → `Finalized`/`Closed`)에 따라 배지 색상(회색, 파란색, 보라색, 녹색 등)이 직관적으로 변하며, 액션 버튼(임시저장, 제출, 리포트 생성 등)이 동적으로 나타나거나 비활성화됩니다.
* **STT(음성 인식) 보조 뷰**: 화면 우측 사이드 패널에 STT 원문 텍스트가 표시되며, 이는 "참고용"임을 알리는 UI와 클립보드 복사 기능을 제공하여 심사자가 내용을 쉽게 옮겨 적을 수 있도록 돕습니다.
* **초고속 리스트 조회**: 10,000건 이상의 데이터도 지연 없이 볼 수 있도록 커서 기반 페이지네이션과 디바운스가 적용된 필터링/검색 기능이 제공됩니다.

**③ Bulk Import 모니터링 (관리자 관제)**
* **시각적 장애 인지 (Drill-down)**: 전체, 성공 건수는 초록색으로 묶고, 실패 건수가 포함된 `PARTIAL_SUCCESS`나 `FAILED` 상태는 강렬한 주황색/적색 배지로 표시해 운영자가 즉각 인지할 수 있습니다.
* **행(Row) 단위 에러 분석**: 에러가 난 파일의 상세 보기(사이드 패널 또는 슬라이드 오버)를 열면, 수천 건의 데이터 중 "몇 번째 라인, 어떤 필드"가 문제인지(예: '품목 코드 누락') 아코디언이나 팝오버로 상세히 알려줍니다.
* **안전한 제어**: 에러 데이터 표출 시 민감 정보(주민번호 등)는 마스킹 처리되며, 실수로 작업을 취소하거나 재처리하지 않도록 강력한 '경고/확인 모달(Destructive Modal)'을 배치합니다.

**결론**: Tailwind CSS와 shadcn/ui 기반으로 통일된 토큰을 사용하여 디자인은 매우 일관되고 모던하며, 모든 페이지는 **사용자의 역할(Role)과 데이터의 상태(Status)** 에 맞춰 UI 요소(메뉴, 버튼, 알림)가 영리하게 통제되는 B2B 엔터프라이즈 환경이 구성될 것입니다.
