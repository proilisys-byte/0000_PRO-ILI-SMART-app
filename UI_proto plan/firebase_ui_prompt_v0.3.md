You are a senior product designer and frontend engineer.

Create a commercialization landing page for “PRO ILI SMART,” a B2B SaaS product for manufacturing quality teams.

[Primary Goal]
This is not just a product introduction page. It is a go-to-market landing page designed to generate interest, demo requests, and pilot inquiries.

A visitor should immediately understand:
1. Who this product is for
2. What quality-operation problems it solves
3. Why it matters now
4. How the workflow changes after adoption
5. What action they should take next

[Product Definition]
Product name: PRO ILI SMART

Category:
AI-powered quality operations SaaS for manufacturing teams

Primary users:
- Quality Assurance and Quality Control teams
- Manufacturing site or plant managers
- Internal and external audit stakeholders
- Quality leaders responsible for non-conformance follow-up
- Decision-makers who need visibility into cost of poor quality and ROI

[Core Value Proposition]
PRO ILI SMART helps manufacturing quality teams run quality operations as a connected workflow, not as disconnected documents and manual follow-ups.

The product should be positioned around these five core capabilities:
1. Smart Audit
   Helps structure field data and audit evidence into faster audit reporting
2. NC Management
   Manages non-conformance cases and follow-up actions in a systematic way
3. Zero-UI Capture
   Reduces field input burden through speech and vision-assisted capture flows
4. Lean COPQ / ROI
   Makes cost of poor quality and improvement priorities more visible
5. Bulk Import Admin
   Lowers onboarding friction with CSV / Excel-based bulk import and admin tracking

[Important Product Context]
Reflect the following product characteristics throughout the page:
- ISO 9001-oriented audit and quality operations context
- Zero-UI concept for reducing frontline input complexity
- Insert-only audit log and traceability-oriented trust model
- Role-based access and admin/user separation
- Bulk import support for faster onboarding
- Audit, non-conformance, and cost analysis are part of one connected operating flow
- This is not a generic AI chatbot; it is a quality operations system built for actual manufacturing workflows

[Landing Page CTA]
Primary CTA should be one or more of the following:
- Request a Demo
- Book a Consultation
- Ask About a Pilot
- Contact Sales

Secondary CTA options:
- View Product Overview
- Explore Core Capabilities
- See Use Cases

[Tone of Voice]
- B2B SaaS for industrial / manufacturing buyers
- Trustworthy, operational, precise, and practical
- Avoid hype-heavy startup language
- Avoid vague phrases like:
  “transform your future”
  “unlock the power of AI”
  “game-changing innovation”
  “revolutionize everything”
- Messaging should be clear enough for both executives and practitioners
- Use concrete problem/solution language
- Emphasize workflow clarity, operational trust, and adoption readiness

[Design Direction]
- Premium but restrained B2B SaaS landing page
- Calm, credible, and structured visual design
- Neutral palette with one disciplined accent color
- Avoid flashy AI-startup aesthetics, neon gradients, glowing blobs, or purple/blue gradient clichés
- Avoid the generic three-column feature-card SaaS template
- Mostly left-aligned layout
- Clear hierarchy, generous whitespace, and strong content structure
- Include dark mode toggle
- Fully responsive
- Make it presentation-ready for real customer meetings

[Required Sections]
The landing page must include the following sections.

1. Hero
- A clear one-line value proposition
- A subheadline that identifies the current pain of manufacturing quality teams
- Primary CTA and secondary CTA
- A product mockup or workflow visualization
- Position the product clearly as an AI-powered quality operations system

2. Problem
- Show 3 to 5 practical problems quality teams face today
- Examples:
  - Audit preparation is document-heavy and time-consuming
  - Frontline data entry is burdensome
  - Non-conformance follow-up is hard to track
  - COPQ visibility is weak
  - Initial data setup and migration are slow
- Use operational, specific language rather than generic marketing copy

3. Solution
- Explain how PRO ILI SMART solves these issues
- Present it as an operating flow, not a feature list
- Example logic:
  field capture → audit structuring → non-conformance action → cost analysis → management visibility

4. Core Capabilities
Include the following:
- Smart Audit
- NC Management
- Zero-UI Capture
- Lean COPQ / ROI
- Bulk Import Admin

Do not present these as five isolated marketing cards.
Instead, connect them as one coherent quality operations narrative or step-based structure.

5. Workflow
- Visually show the end-to-end flow from field activity to management decision support
- Example:
  field capture / evidence intake → audit session organization → report generation → NC action tracking → COPQ / ROI analysis → admin oversight
- This should be one of the strongest visual sections on the page

6. Trust / Why Us
Communicate why the product is credible for real manufacturing environments:
- Built for manufacturing quality operations
- Aligned with ISO 9001-oriented audit context
- Traceability and audit-log mindset
- Role-based operational control
- Faster onboarding through import and admin tooling
- Designed as an operational system, not a superficial AI demo

7. Use Cases
Include around 3 focused use cases for manufacturing quality teams, such as:
- Reducing audit preparation effort
- Structuring non-conformance follow-up
- Improving visibility into quality cost priorities
Keep them concise and concrete.

8. Expected Outcomes
Present realistic outcomes in a balanced way.
Do not invent aggressive numbers unless clearly supported.
Prefer statements such as:
- Shorter audit preparation cycles
- Lower frontline input burden
- Better follow-up traceability
- Better visibility into quality cost drivers
- Faster onboarding of existing quality data

9. Final CTA
- End with a strong conversion block for demo or pilot inquiry
- Include a simple lead form layout or inquiry panel
- Keep the CTA wording natural for B2B buyers

10. Footer
- Product name
- Short product summary
- CTA button
- Anchor links to key sections

[Content Guidance]
Reflect these concepts in the messaging and visuals:
- Audit sessions and workspace-style operational flow
- Administrative visibility for bulk import jobs and statuses
- Error visibility, status tracking, and operational transparency
- A single platform connecting field capture and management oversight
- Different user roles such as admin, auditor, viewer, and operator
- Traceability, structured records, and operational reliability

[Implementation Requirements]
- Deliver as a single HTML file
- Include CSS and JS inline
- Use semantic HTML
- Support dark mode
- Support responsive behavior
- Consider accessibility
- Use restrained scroll animation only
- Keep performance practical
- Include a refined SaaS-style product mockup section
- Create a simple custom SVG logo instead of text-only branding
- Use placeholder links where needed, but structure them like a real production landing page

[Copywriting Requirements]
- Write all landing page copy in English
- Keep headlines clear, direct, and product-specific
- Avoid abstract slogans
- Good examples of tone:
  “Run manufacturing quality operations as a connected workflow.”
  “From field capture to corrective action, keep quality work moving.”
  “Bring audit, non-conformance, and quality cost visibility into one system.”
  “Reduce documentation burden and improve operational traceability.”
- Bad examples:
  “Empower your innovation journey”
  “Experience the future of AI”
  “Unlock limitless potential”
  “Reinvent quality with smart intelligence”

[Information Priority]
Within the first few seconds, the visitor should understand:
- Who this is for
- What it solves
- How it works
- Why it is trustworthy
- What action to take next

[Expected Output]
Create:
1. A polished business landing page HTML
2. Realistic English copy for B2B manufacturing buyers
3. A trustworthy, premium, restrained visual style
4. A workflow-centered narrative rather than a disconnected feature list
5. A structure that can be easily refined further inside Firebase Studio

- Prioritize clarity over decoration
- Make the page feel credible enough for a real enterprise sales conversation

  PRO ILI SMART is a quality operations system for manufacturing teams
- Avoid generic SaaS starter-template patterns
- Show how the product connects field activity, audit work, corrective action, analytics, and admin control in one operating model
