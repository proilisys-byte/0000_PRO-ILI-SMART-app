# Firebase Studio 용 PRO ALI SMART 랜딩페이지 프롬프트

아래의 프롬프트를 복사하여 Firebase Studio(또는 v0, Project IDX, Cursor 등 AI UI 생성 도구)에 입력하십시오. PRD와 SRS, 그리고 구체적인 UI 기획 문서(UI-000 ~ UI-061)의 핵심 가치가 모두 반영된 고해상도(High-fidelity) 프롬프트입니다.

---

## 📋 프롬프트 복사 영역

**[역할 및 목적 (Role & Objective)]**
당신은 최고 수준의 B2B SaaS UI/UX 디자이너이자 숙련된 Frontend 엔지니어(Next.js, React, Tailwind CSS, shadcn/ui 전문)입니다. 
제공된 프로젝트 컨텍스트를 기반으로 'PRO ALI SMART(스마트 제조 품질혁신 플랫폼)'의 **사업화 랜딩페이지(Landing Page)** 코드를 완벽하게 구현해주세요.
잠재 고객(중소·중견 제조기업 대표 및 품질팀장)이 보았을 때 압도적인 신뢰감과 혁신성을 느낄 수 있도록, **현대적이고 프리미엄하며 동적인(Dynamic) 인터랙티브 디자인**을 적용해야 합니다. 단순한 MVP 템플릿 느낌이 나면 안 됩니다.

**[프로젝트 핵심 요약 (Context)]**
- **제품명:** PRO ALI SMART
- **타겟 고객:** 반도체 소부장 등 중소/중견 제조기업
- **해결하고자 하는 문제 (Pain Point):** 현장 수기 데이터 기록의 마찰, 원청 Audit 심사 준비 시 120시간 이상의 문서 매핑 수작업, 부적합(NC) 대응 지연으로 인한 품질 비용(COPQ) 낭비.
- **핵심 가치 (Value Proposition):** 
  1) Zero-UI (음성 STT/비전 AI) 기반 마찰 없는 현장 데이터 수집
  2) AI 기반 Smart Audit 엔진으로 10분 내 ISO 9001 증빙 리포트 100% 자동 생성
  3) 클라우드/AI 자동화 아키텍처를 통한 초기 도입비용 $0, 체감 유지비 월 12만원 달성

**[디자인 시스템 & 시각적 방향성 (Aesthetics)]**
- **테마:** Dark Mode 중심의 세련된 엔터프라이즈 SaaS 테마.
- **컬러 팔레트:** Deep Space Black (#0F172A) 배경, 브랜드 포인트 컬러로 Vibrant Cyan (혁신/AI 상징) 및 Emerald Green (통과/안전 상징) 사용.
- **UI 패턴:** Glassmorphism (반투명 유리 텍스처 효과), 부드러운 블러(Blur) 그라데이션 백그라운드 적용.
- **애니메이션 & 인터랙션:** 
  - 스크롤 시 부드러운 Fade-in 및 Slide-up 효과 (Framer Motion 등 활용).
  - 카드 호버 시 미세한 크기 확대, 테두리 글로우(Glow) 효과 등 마이크로 애니메이션 적극 활용.
- **타이포그래피:** 가독성이 뛰어나고 모던한 느낌의 산세리프 폰트 (Inter, Pretendard 등).

**[랜딩페이지 섹션별 상세 구성 요소]**

**1. Hero Section (최상단 메인 영역)**
- **Headline:** "터치조차 필요 없는 혁신, 품질 관리의 Zero-UI 시대를 열다."
- **Sub-headline:** "원청 Audit 통과부터 긴급 NC 시정까지. 현장의 소음 속 음성 데이터가 10분 만에 완벽한 ISO 9001 증빙 리포트로 변환됩니다."
- **CTA 버튼:** 
  - Primary: `[무료 도입 컨설팅 신청]` (빛나는 글로우 효과 적용)
  - Secondary: `[플랫폼 아키텍처 보기]`
- **Visual Element:** 단순 이미지가 아닌, 현장의 음성 파형(STT) 코드가 클라우드를 거쳐 대시보드 리포트로 변환되는 과정을 보여주는 세련된 **추상적 UI Mockup** (CSS와 아이콘을 활용하여 구현).

**2. Before & After (Pain Points vs Solution)**
- 기존의 방식 (종이 기록, 야근을 통한 엑셀 매핑, 데이터 분실)과 PRO ALI SMART 방식 (실시간 동기화, AI 자동 매핑)을 대비하여 직관적으로 보여주는 비교 컨테이너.

**3. Core Features (4대 핵심 기능)** - 반응형 카드 그리드
- **🎙️ Zero-UI 수집기:** "기록을 위해 장갑을 벗지 마십시오." 소음 및 오염 환경에서도 작동하는 실시간 음성(STT) 및 비전 AI 수집.
- **📄 Smart Audit 엔진:** "120시간을 10분으로." 수집된 데이터와 원청 템플릿(ISO 9001 등)을 AI가 자동 매핑하여 증빙 리포트(PDF) 생성.
- **🚨 긴급 NC 시정 패키지:** "부적합 통보 시 5분 내 시정 조치." 통보 사유 자동 파싱 및 진행률 추적을 통한 무결점 시정 방어.
- **📈 Lean 진단 (COPQ):** "숨은 낭비를 수익으로." 데이터 기반 4대 낭비를 금액으로 환산하는 ROI 대시보드 및 트렌드 시각화.

**4. Trust, Security & Compliance (무결성과 보안)**
- B2B의 핵심인 '보안/무결성' 강조 섹션.
- 주요 키워드: "Insert-only 방식 클라우드 DB 감사 로그", "AES-256 암호화", "RBAC 역할 기반 2단계 접근 제어(Admin/User)".
- 시각물: 자물쇠/보안 실드 아이콘과 함께 '데이터 유실률 0%', '위변조 100% 차단' 뱃지 UI 배치.

**5. Metrics & ROI (도입 성과 강조)**
- 대형 타이포그래피와 카운팅 애니메이션(가능할 경우)으로 수치 임팩트 극대화:
  - **120h → 10m** (리포트 작성 시간 99% 단축)
  - **$0** (MVP 초기 도입 인프라 비용)
  - **1 Sprint** (시스템 도입 및 적용 기간)

**6. Footer & Final CTA (하단 전환 영역)**
- **Headline:** "당신의 품질 비용(COPQ)을 지금 바로 영업 이익으로 전환하세요."
- **CTA:** 간단한 회사명/이메일 입력 폼 + `[라이브 데모 시작하기]` 버튼.
- 하단: 로고, 저작권, 개인정보처리방침, Terms 등 기본 Footer.

**[기술적 제약 및 코딩 요구사항 (Technical Constraints)]**
- **단일 파일 컴포넌트:** 제공하는 코드는 즉시 랜더링 가능한 완벽한 수준이어야 합니다.
- **Tailwind CSS 의존성:** 모든 스타일링은 Tailwind Utility Class로 작성하며 임의의 커스텀 CSS 파일 추가를 지양합니다.
- **아이콘 사용:** Lucide React 아이콘 라이브러리를 적극 활용하여 시각적 완성도를 극대화하십시오.
- **가짜 이미지(Placeholder) 지양:** 단순한 `<img>` 태그로 회색 박스를 넣는 대신, Tailwind CSS로 스타일링된 미니 대시보드 컴포넌트, 코드 블록, 상태 뱃지, 차트 바 등을 만들어 실제 앱의 UI 일부를 보여주는 방식으로 구성하십시오.
- **반응형(Responsive) 완벽 대응:** 모바일(sm), 태블릿(md), 데스크탑(lg/xl) 화면에서 레이아웃이 깨지지 않도록 구성하십시오.
